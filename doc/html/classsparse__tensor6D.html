Detailed Description

template<class T>
class sparse_tensor6D< T >

Template class for 6D tensors This classes do not provide an allocator.

They are allocated automatically using the costum constructor tesor?D( int int ....) The default constructor can be used, but only to create dummy tensors, that needs to be assigned using the assignment operator (=)

Memebers are all public.

  • n1, n2, ... contains the dimensions
  • the pointer data contains the data in col major order, such that it can be pass to BLAS/LAPACK easily as A.data
  • reading and writing single elements is done using the () operator so element 1,2,5 of tensor A is accessed A(1,2,5)
