\doxysubsubsection*{Classes and utlities}

The code is currently strctured to produce 3 executables and a library


\begin{DoxyItemize}
\item lib\+N\+RG -\/ source code in src/nrg\+: the core of truspace, contains the \mbox{\hyperlink{classNRG}{N\+RG}} routines as well as some base class to derive for specialization, namely\+:
\begin{DoxyItemize}
\item \mbox{\hyperlink{classNRG}{N\+RG}} \+: The core nrg engine, model agnostic, supporting also \textquotesingle{}Sweep\textquotesingle{}
\item \mbox{\hyperlink{classHamiltonian}{Hamiltonian}} \+: Abstract class to handle the computation of the T\+SA \mbox{\hyperlink{classHamiltonian}{Hamiltonian}}
\item \mbox{\hyperlink{classstates}{states}} \+: Abstract class that calculates and holds all the informations regarding the computation basis
\item \mbox{\hyperlink{classmatrix__elements}{matrix\+\_\+elements}} \+: Abstract class that calculates and holds all the information about matrix element of the fields on the computational basis
\item \mbox{\hyperlink{classparameters}{parameters}} \+: Class that holds the nrg parameters
\item \mbox{\hyperlink{classfilenames}{filenames}} \+: Helper class to manage output and swap files names
\item \mbox{\hyperlink{classtensor2D}{tensor2D}}, \mbox{\hyperlink{classtensor3D}{tensor3D}}, \mbox{\hyperlink{classtensor4D}{tensor4D}}, \mbox{\hyperlink{classtensor5D}{tensor5D}}, \mbox{\hyperlink{classtensor6D}{tensor6D}} \+: helper template class to handle 2D, 3D, 4D, 5D and 6D tensors. It ensures memory contiguity and automatic deallocation when out of scope, without forcing compilation-\/time sizes.
\item \mbox{\hyperlink{classsparse__tensor3D}{sparse\+\_\+tensor3D}} and \mbox{\hyperlink{classsparse__tensor6D}{sparse\+\_\+tensor6D}} \+:helper template class to handle 3D, and 6D sparse tensors.
\end{DoxyItemize}
\item truspace.\+x and truspace\+\_\+\+M\+P\+I.\+x -\/ the main executables, serial (with some multithreading support) and M\+PI respectively. The available classes and files are
\begin{DoxyItemize}
\item \mbox{\hyperlink{classminimal__model__parameters}{minimal\+\_\+model\+\_\+parameters}} \+: class that handles the minimal model input reading, the reading of fields and structure constants and the analysis of symmetry subspaces.
\item \mbox{\hyperlink{classworker}{worker}} \+: class that takes care of running the different parts of the code after all parameters are set
\item \mbox{\hyperlink{classminimal__model__states}{minimal\+\_\+model\+\_\+states}}\+: class that calculates and holds all the informations regarding on the conformal computation basis. Derived from \mbox{\hyperlink{classstates}{states}}
\item \mbox{\hyperlink{classchirME}{chir\+ME}} \+: class that calculates and holds all the information about matrix element of the fields on the conformal computational basis. Derived from \mbox{\hyperlink{classmatrix__elements}{matrix\+\_\+elements}}
\item \mbox{\hyperlink{classminimal__model__filenames}{minimal\+\_\+model\+\_\+filenames}} \+: helper class to manage output and files names specific for the minimal model. Derived from \mbox{\hyperlink{classfilenames}{filenames}}
\item \mbox{\hyperlink{classminimal__model__Hamiltonian}{minimal\+\_\+model\+\_\+\+Hamiltonian}} \+: class that handles the computation and the matrix form of the T\+SA \mbox{\hyperlink{classHamiltonian}{Hamiltonian}} of the perturbed minimal model. Derived from \mbox{\hyperlink{classHamiltonian}{Hamiltonian}}
\item \mbox{\hyperlink{classdiag}{diag}}\+: helper class that contains Numerical Recipies diagonalization routines for long double (required to calculate the conformal computational basis)
\item \mbox{\hyperlink{minimal__model__config_8h}{minimal\+\_\+model\+\_\+config.\+h}} Configuration file holding version number, some hard-\/coded limits that effect array dimensions, constants and macros
\item \mbox{\hyperlink{block_8h}{block.\+h}} Contains a routine to identify symmetry subspace by the analysis of the interaction matrix.
\item \mbox{\hyperlink{characters_8h}{characters.\+h}} Set of helper functions to calculate integers partitions and manage Gi\+NaC computation of character expansion
\item \mbox{\hyperlink{cpt_8h}{cpt.\+h}} Set of helper function to calculate structure constant of Minimal C\+F\+Ts
\item \mbox{\hyperlink{gamma_8h}{gamma.\+h}} Computation of gamma function
\end{DoxyItemize}
\item fields\+\_\+and\+\_\+structure\+\_\+constants.\+x -\/ executable that calculates the fields list and structure constants for arbitrary unitary minimal models. It also produces fields file and structure constants file that can be used in truspace.\+x and truspace\+\_\+\+M\+P\+I.\+x
\end{DoxyItemize}

The model-\/agnostic nature of the \mbox{\hyperlink{classNRG}{N\+RG}} class should allow easy extension of the current code to other Quantum Hamiltonians.

\doxysubsubsection*{Code architecture}

The following diagram explains how the various objects are created and called.



The flow is the following\+:


\begin{DoxyItemize}
\item The main, called \mbox{\hyperlink{truspace_8cpp}{truspace.\+cpp}}
\item creates an instance of \mbox{\hyperlink{classminimal__model__parameters}{minimal\+\_\+model\+\_\+parameters}} from the input file, then calls parameters\+::analyse\+\_\+subspaces that calculates the size of Hilbert space, the structure constans and tries to find symmetry subspaces in the Hilbert space
\item creates and instace of \mbox{\hyperlink{classworker}{worker}} and runs it
\item \mbox{\hyperlink{classworker}{worker}} iterates through momentum subspaces and symmetry subspaces. For each of them
\begin{DoxyItemize}
\item creates an instance of \mbox{\hyperlink{classminimal__model__states}{minimal\+\_\+model\+\_\+states}}, which calculates (or reads from file) and hold the computational conformal basis. The basis is identified by removing null-\/vectors and then performing a orthgonalization
\item creates an instance if \mbox{\hyperlink{classminimal__model__filenames}{minimal\+\_\+model\+\_\+filenames}}, which holds the strings identifying the various output files
\item creates an instance of \mbox{\hyperlink{classchirME}{chir\+ME}}, which calculates (or reads from file) and hold the matrix elements of the pertubation(s) by calling \mbox{\hyperlink{classchirME_a8c1712c4ecb24ce73156f5d23a4835fa}{chir\+M\+E\+::calculate\+\_\+or\+\_\+read\+\_\+chir\+ME}} Matrix element are stored on the chiral states to save memory, which means that the complete matrix element will be the product of the contribution for chiral and anti-\/chiral components. They are stored in \mbox{\hyperlink{classchirME_aec195b69a1aa902a2d88c0bd1f469b15}{chir\+M\+E\+::me\+\_\+chi\+\_\+ortho}}. If the expectation value of an operator is asked in the input file, it also calculates chiral matrix elements for the specified operator. The matrix elements are stored in \mbox{\hyperlink{classchirME_a2c979d1744b25f54f14f9f7bf60769a5}{chir\+M\+E\+::me\+\_\+chi\+\_\+ortho\+\_\+op}}.
\item iterates through values of {\ttfamily R}, for each of them
\begin{DoxyItemize}
\item creates and instance of \mbox{\hyperlink{classminimal__model__Hamiltonian}{minimal\+\_\+model\+\_\+\+Hamiltonian}}, which hold the hamiltonian matrix and a set of routines to calculate the parts of the hamiltonian relevant for N\+R\+G/\+Sweep
\item creates and \mbox{\hyperlink{classNRG}{N\+RG}} object and runs it
\begin{DoxyItemize}
\item \mbox{\hyperlink{classNRG}{N\+RG}} performs \mbox{\hyperlink{classNRG}{N\+RG}} iteration and Sweeps, calculates eigenvalues for each N\+R\+G/\+Sweep iteration, and, if requested in the input file, eigenvectors and expectation values of an operator. For eigenvectors and expectation values, the printed value are relative to the last \mbox{\hyperlink{classNRG}{N\+RG}} iteration.
\end{DoxyItemize}
\end{DoxyItemize}
\end{DoxyItemize}
\end{DoxyItemize}

\doxysubsubsection*{How to extened Truspace}

If you want to extend truspace, you will need to create your own derived version of \mbox{\hyperlink{classstates}{states}}, \mbox{\hyperlink{classmatrix__elements}{matrix\+\_\+elements}}, \mbox{\hyperlink{classHamiltonian}{Hamiltonian}}, \mbox{\hyperlink{classparameters}{parameters}} and \mbox{\hyperlink{classfilenames}{filenames}}. You don\textquotesingle{}t really need to respect the public interfaces for \mbox{\hyperlink{classstates}{states}}, \mbox{\hyperlink{classchirME}{chir\+ME}}, as these are only used by \mbox{\hyperlink{classHamiltonian}{Hamiltonian}}, that you are rewirting anyway. Instead, the interfaces of \mbox{\hyperlink{classHamiltonian}{Hamiltonian}} are important to \mbox{\hyperlink{classNRG}{N\+RG}}, in particular


\begin{DoxyItemize}
\item \mbox{\hyperlink{classHamiltonian_ab3c734fffdccf18d83dd9253129faaff}{Hamiltonian\+::init}} -\/ Initialization of the \mbox{\hyperlink{classHamiltonian}{Hamiltonian}}, meaning the filling of the matrix element for the first \mbox{\hyperlink{classNRG}{N\+RG}} iteration
\item \mbox{\hyperlink{classHamiltonian_a23db23fd29e7a4a70e8d9bc0a07f57fb}{Hamiltonian\+::\+N\+R\+G\+\_\+block\+\_\+A}} -\/ Fills top-\/left part of the \mbox{\hyperlink{classHamiltonian}{Hamiltonian}} matrix, usually diagonal which contains the eigenvaues of the previous iteration
\item \mbox{\hyperlink{classHamiltonian_aa4ce99fd925f019ee7d09d0819e0838c}{Hamiltonian\+::\+N\+R\+G\+\_\+block\+\_\+\+BC}} -\/ Fills the bottom-\/left and top-\/right parts of the \mbox{\hyperlink{classHamiltonian}{Hamiltonian}} matrix, which contains the expectaion value of the perturbing operator(s) between previous step eigenstates and the newly added states of the computational basis
\item \mbox{\hyperlink{classHamiltonian_a54a08459692f4ec58f08caec3cf79848}{Hamiltonian\+::\+N\+R\+G\+\_\+block\+\_\+D}} -\/ Fills the bottom-\/right part of the \mbox{\hyperlink{classHamiltonian}{Hamiltonian}} matrix, which contains the expectaion value of the perturbing operator(s) on the newly added states of the computational basis
\item \mbox{\hyperlink{classHamiltonian_a9bbe852b73ed7fed62f00653f65d4d93}{Hamiltonian\+::sweep\+\_\+block\+\_\+\+BC}} -\/ Fills the bottom-\/left and top-\/right parts of the \mbox{\hyperlink{classHamiltonian}{Hamiltonian}} matrix, which contains the expectaion value of the hamiltonian between previous step eigenstates and eigenstates of the previous step same iteration
\item \mbox{\hyperlink{classHamiltonian_ab17354d805e72f8e171f1d4b42d54856}{Hamiltonian\+::\+Msize}} -\/ Size of the \mbox{\hyperlink{classHamiltonian}{Hamiltonian}} matrix at each \mbox{\hyperlink{classNRG}{N\+RG}} iteration
\item \mbox{\hyperlink{classHamiltonian_a7829a6c2690f5ffcc105ecc9a7514dc7}{Hamiltonian\+::print\+\_\+eigen\+Values}} -\/ Prints eigenvalues to file
\item \mbox{\hyperlink{classHamiltonian_a3b5878170ebdcf7ce6fc000cb3668fc6}{Hamiltonian\+::print\+\_\+eigen\+Vectors}} -\/ Prints eigenvectors to file
\item \mbox{\hyperlink{classmatrix__elements_a010e61684898a6820d4db603f68ef2a3}{matrix\+\_\+elements\+::calculate\+\_\+\+Exp\+Val}} -\/ Calculates expextation value on the final eigenstates of a given operator. The only interface of \mbox{\hyperlink{classmatrix__elements}{matrix\+\_\+elements}} to be strictly respected.
\end{DoxyItemize}

An example of such an application to the Quantum Harmonic oscillator in 1D is available in src/truspace\+\_\+extension\+\_\+example
