\subsection{Detailed Description}
Driver Class for states, matrix element and \mbox{\hyperlink{classNRG}{N\+RG}} calculation. 

It takes care of
\begin{DoxyItemize}
\item looping through the subspace found by parameters\+::analyze\+\_\+subspace
\item finding chiral and non-\/chiral base states in each subspace
\item calling \mbox{\hyperlink{classNRG}{N\+RG}} routine on each subspace
\item calculating Matrix element on the eigenstates found, in each subspace. If the operator connects a set of subspaces, then those subspaces are diagonalized at the same time
\end{DoxyItemize}
