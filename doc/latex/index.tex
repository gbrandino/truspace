\subsubsection*{Classes and utlities}

The available classes are


\begin{DoxyItemize}
\item \mbox{\hyperlink{classparameters}{parameters}} \+: class that handles the input reading, the calculation of the structure constants and the analysis of symmetry subspaces.
\item \mbox{\hyperlink{classworker}{worker}} \+: class that takes care of running the different parts of the code after all parameters are set
\item \mbox{\hyperlink{classstates}{states}}\+: class that calculates and holds all the informations regarding the computation basis
\item \mbox{\hyperlink{classchirME}{chir\+ME}} \+: class that calculates and holds all the information about matrix element of the fields on the computational basis
\item \mbox{\hyperlink{classfilenames}{filenames}} \+: helper class to manage output and swap files names
\item \mbox{\hyperlink{classHamiltonian}{Hamiltonian}} \+: class that handles the computation and the matrix form of the T\+SA \mbox{\hyperlink{classHamiltonian}{Hamiltonian}} of the perturbed model
\item \mbox{\hyperlink{classdiag}{diag}}\+: helper class that contains Numerical Recipies diagonalization routines for long double (required to calculate the conformal computational basis)
\item \mbox{\hyperlink{classtensor2D}{tensor2D}}, \mbox{\hyperlink{classtensor3D}{tensor3D}}, \mbox{\hyperlink{classtensor4D}{tensor4D}}, \mbox{\hyperlink{classtensor5D}{tensor5D}}, \mbox{\hyperlink{classtensor6D}{tensor6D}} \+: helper template class to handle 2D, 3D, 4D, 5D and 6D tensors. It ensures memory contiguity and automatic deallocation when out of scope, without forcing compilation-\/time sizes.
\item \mbox{\hyperlink{classNRG}{N\+RG}} \+: model-\/agnostic full diagonalization, {\ttfamily \mbox{\hyperlink{classNRG}{N\+RG}}} and {\ttfamily Sweep} routine
\end{DoxyItemize}

Moreover, the are a series of helper functions


\begin{DoxyItemize}
\item \mbox{\hyperlink{config_8h}{config.\+h}} Configuration file holding version number, some hard-\/coded limits that effect array dimensions, constants and macros
\item \mbox{\hyperlink{block_8h}{block.\+h}} Contains a routine to identify symmetry subspace by the analysis of the interaction matrix.
\item \mbox{\hyperlink{characters_8h}{characters.\+h}} Set of helper functions to calculate integers partitions and manage Gi\+NaC computation of character expansion
\item \mbox{\hyperlink{cpt_8h}{cpt.\+h}} Set of helper function to calculate structure constant of Minimal C\+F\+Ts
\item \mbox{\hyperlink{gamma_8h}{gamma.\+h}} Computation of gamma function
\end{DoxyItemize}

The model-\/agnostic nature of the \mbox{\hyperlink{classNRG}{N\+RG}} class should allow easy extension of the current code to other Quantum Hamiltonians.

The flow is the following\+:

\end{DoxyItemize}
\item \mbox{\hyperlink{classworker}{worker}}
\begin{DoxyItemize}
\item iterates through momentum subspaces and symmetry subspaces. For each of them
\begin{DoxyItemize}
\item creates an instance of \mbox{\hyperlink{classstates}{states}}, which calculates (or reads from file) and hold the computational conformal basis. The basis is identified by removing null-\/vectors and then performing a orthgonalization
\item creates an instance if \mbox{\hyperlink{classfilenames}{filenames}}, which holds the strings identifying the various output files
\item creates an instance of \mbox{\hyperlink{classchirME}{chir\+ME}}, which calculates (or reads from file) and hold the matrix elements of the pertubation(s) by calling \mbox{\hyperlink{classchirME_a9a7e36cc974d91607112bdf552ed40fc}{chir\+M\+E\+::calculate\+\_\+or\+\_\+read\+\_\+chir\+ME}} Matrix element are stored on the chiral states to save memory, which means that the complete matrix element will be the product of the contribution for chiral and anti-\/chiral components. The matrix elements are stored in \mbox{\hyperlink{classchirME_ae206d3f68100f496ec7e3ea09bcf2c0a}{chir\+M\+E\+::me\+\_\+chi\+\_\+ortho\+\_\+op\+\_\+l}} and \mbox{\hyperlink{classchirME_aba75f5ca87a3598e54eecb2aaa3cca34}{chir\+M\+E\+::me\+\_\+chi\+\_\+ortho\+\_\+op\+\_\+r}} for the chiral and anti-\/chiral component of the operator.

\subsubsection*{How to extened Truspace}

If you want to extend truspace, you will need to create your own version of \mbox{\hyperlink{classstates}{states}}, \mbox{\hyperlink{classchirME}{chir\+ME}} and \mbox{\hyperlink{classHamiltonian}{Hamiltonian}}. You don\textquotesingle{}t really need to respect the public interfaces for \mbox{\hyperlink{classstates}{states}}, \mbox{\hyperlink{classchirME}{chir\+ME}}, as these are only used by \mbox{\hyperlink{classHamiltonian}{Hamiltonian}}, that you are rewirting anyway. Instead, the interfaces of \mbox{\hyperlink{classHamiltonian}{Hamiltonian}} are important to \mbox{\hyperlink{classNRG}{N\+RG}}, in particular


\begin{DoxyItemize}
\item \mbox{\hyperlink{classHamiltonian_a04675b0b538bfb01d2f0aacf55ad4a7e}{Hamiltonian\+::init}} -\/ Initialization of the \mbox{\hyperlink{classHamiltonian}{Hamiltonian}}, meaning the filling of the matrix element for the first \mbox{\hyperlink{classNRG}{N\+RG}} iteration
\item \mbox{\hyperlink{classHamiltonian_a8cc203b3b630ada7845f3c59606c3d27}{Hamiltonian\+::\+N\+R\+G\+\_\+block\+\_\+A}} -\/ Fills top-\/left part of the \mbox{\hyperlink{classHamiltonian}{Hamiltonian}} matrix, usually diagonal which contains the eigenvaues of the previous iteration
\item \mbox{\hyperlink{classHamiltonian_a8e57b289129fc6039c761c22ae45a27a}{Hamiltonian\+::\+N\+R\+G\+\_\+block\+\_\+\+BC}} -\/ Fills the bottom-\/left and top-\/right parts of the \mbox{\hyperlink{classHamiltonian}{Hamiltonian}} matrix, which contains the expectaion value of the perturbing operator(s) between previous step eigenstates and the newly added states of the computational basis
\item \mbox{\hyperlink{classHamiltonian_a5da029dcda9ab74d5beb045694bcbc47}{Hamiltonian\+::\+N\+R\+G\+\_\+block\+\_\+D}} -\/ Fills the bottom-\/right part of the \mbox{\hyperlink{classHamiltonian}{Hamiltonian}} matrix, which contains the expectaion value of the perturbing operator(s) on the newly added states of the computational basis
\item \mbox{\hyperlink{classHamiltonian_a6a08e22b729adbc783c1770b21510ee2}{Hamiltonian\+::sweep\+\_\+block\+\_\+\+BC}} -\/ Fills the bottom-\/left and top-\/right parts of the \mbox{\hyperlink{classHamiltonian}{Hamiltonian}} matrix, which contains the expectaion value of the hamiltonian between previous step eigenstates and eigenstates of the previous step same iteration
\item \mbox{\hyperlink{classHamiltonian_ab17354d805e72f8e171f1d4b42d54856}{Hamiltonian\+::\+Msize}} -\/ Size of the \mbox{\hyperlink{classHamiltonian}{Hamiltonian}} matrix at each \mbox{\hyperlink{classNRG}{N\+RG}} iteration
\item \mbox{\hyperlink{classHamiltonian_ab70ecbcd7f5ce1cf3ba9753c2411e9fc}{Hamiltonian\+::print\+\_\+eigen\+Values}} -\/ Prints eigenvalues to file
\item \mbox{\hyperlink{classHamiltonian_a8b6c47e52675e438f1b7c780b15da039}{Hamiltonian\+::print\+\_\+eigen\+Vectors}} -\/ Prints eigenvectors to file
\item \mbox{\hyperlink{classchirME_aad56d2574efe19f3da59c6b5ab0ddbdb}{chir\+M\+E\+::calculate\+\_\+\+Exp\+Val}} -\/ Calculates expecation value on the final eigenstates of a given operator. Only interface of \mbox{\hyperlink{classchirME}{chir\+ME}} to be strictly respected. 
\end{DoxyItemize}
