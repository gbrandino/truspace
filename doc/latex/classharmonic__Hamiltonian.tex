\mbox{\hyperlink{classHamiltonian}{Hamiltonian}} Class.

~\newline
 Class that calculates and holds the \mbox{\hyperlink{classHamiltonian}{Hamiltonian}} matrix and the function to calculates the elements needed for \mbox{\hyperlink{classNRG}{N\+RG}} and Sweep. For N\+R\+G/\+Sweep the structure of the matrix is
