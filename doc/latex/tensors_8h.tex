\subsection{Detailed Description}
Set of helper templates class to manage 2D, 3D, 4D, 5D, 6D tensors. 

This classes do not provide an allocator. They are allocated automatically using the costum constructor tesor?D( int int ....) The default constructor can be used, but only to create dummy tensors, that needs to be assigned using the assignment operator (=)

Memebers are all public.
\begin{DoxyItemize}
\item n1, n2, ... contains the dimensions
\item the pointer data contains the data in col major order, such that it can be pass to B\+L\+A\+S/\+L\+A\+P\+A\+CK easily as A.\+data
\item reading and writing single elements is done using the () operator so element 1,2,5 of tensor A is accessed A(1,2,5)
\end{DoxyItemize}
