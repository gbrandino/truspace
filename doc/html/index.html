Classes and utlities

The code is currently strctured to produce 3 executables and a library

  • libNRG - source code in src/nrg: the core of truspace, contains the NRG routines as well as some base class to derive for specialization, namely:
    • NRG : The core nrg engine, model agnostic, supporting also 'Sweep'
    • Hamiltonian : Abstract class to handle the computation of the TSA Hamiltonian
    • states : Abstract class that calculates and holds all the informations regarding the computation basis
    • matrix_elements : Abstract class that calculates and holds all the information about matrix element of the fields on the computational basis
    • parameters : Class that holds the nrg parameters
    • filenames : Helper class to manage output and swap files names
    • tensor2D, tensor3D, tensor4D, tensor5D, tensor6D : helper template class to handle 2D, 3D, 4D, 5D and 6D tensors. It ensures memory contiguity and automatic deallocation when out of scope, without forcing compilation-time sizes.
    • sparse_tensor3D and sparse_tensor6D :helper template class to handle 3D, and 6D sparse tensors.
  • truspace.x and truspace_MPI.x - the main executables, serial (with some multithreading support) and MPI respectively. The available classes and files are
    • minimal_model_parameters : class that handles the minimal model input reading, the reading of fields and structure constants and the analysis of symmetry subspaces.
    • worker : class that takes care of running the different parts of the code after all parameters are set
    • minimal_model_states: class that calculates and holds all the informations regarding on the conformal computation basis. Derived from states
    • chirME : class that calculates and holds all the information about matrix element of the fields on the conformal computational basis. Derived from matrix_elements
    • minimal_model_filenames : helper class to manage output and files names specific for the minimal model. Derived from filenames
    • minimal_model_Hamiltonian : class that handles the computation and the matrix form of the TSA Hamiltonian of the perturbed minimal model. Derived from Hamiltonian
    • diag: helper class that contains Numerical Recipies diagonalization routines for long double (required to calculate the conformal computational basis)
    • minimal_model_config.h Configuration file holding version number, some hard-coded limits that effect array dimensions, constants and macros
    • block.h Contains a routine to identify symmetry subspace by the analysis of the interaction matrix.
    • characters.h Set of helper functions to calculate integers partitions and manage GiNaC computation of character expansion
    • cpt.h Set of helper function to calculate structure constant of Minimal CFTs
    • gamma.h Computation of gamma function
  • fields_and_structure_constants.x - executable that calculates the fields list and structure constants for arbitrary unitary minimal models. It also produces fields file and structure constants file that can be used in truspace.x and truspace_MPI.x

The model-agnostic nature of the NRG class should allow easy extension of the current code to other Quantum Hamiltonians.

Code architecture

The following diagram explains how the various objects are created and called.

The flow is the following:

  • The main, called truspace.cpp
  • creates an instance of minimal_model_parameters from the input file, then calls parameters::analyse_subspaces that calculates the size of Hilbert space, the structure constans and tries to find symmetry subspaces in the Hilbert space
  • creates and instace of worker and runs it
  • worker iterates through momentum subspaces and symmetry subspaces. For each of them
    • creates an instance of minimal_model_states, which calculates (or reads from file) and hold the computational conformal basis. The basis is identified by removing null-vectors and then performing a orthgonalization
    • creates an instance if minimal_model_filenames, which holds the strings identifying the various output files
    • creates an instance of chirME, which calculates (or reads from file) and hold the matrix elements of the pertubation(s) by calling chirME::calculate_or_read_chirME Matrix element are stored on the chiral states to save memory, which means that the complete matrix element will be the product of the contribution for chiral and anti-chiral components. They are stored in chirME::me_chi_ortho. If the expectation value of an operator is asked in the input file, it also calculates chiral matrix elements for the specified operator. The matrix elements are stored in chirME::me_chi_ortho_op.
    • iterates through values of R, for each of them
      • creates and instance of minimal_model_Hamiltonian, which hold the hamiltonian matrix and a set of routines to calculate the parts of the hamiltonian relevant for NRG/Sweep
      • creates and NRG object and runs it
        • NRG performs NRG iteration and Sweeps, calculates eigenvalues for each NRG/Sweep iteration, and, if requested in the input file, eigenvectors and expectation values of an operator. For eigenvectors and expectation values, the printed value are relative to the last NRG iteration.

How to extened Truspace

If you want to extend truspace, you will need to create your own derived version of states, matrix_elements, Hamiltonian, parameters and filenames. You don't really need to respect the public interfaces for states, chirME, as these are only used by Hamiltonian, that you are rewirting anyway. Instead, the interfaces of Hamiltonian are important to NRG, in particular

  • Hamiltonian::init - Initialization of the Hamiltonian, meaning the filling of the matrix element for the first NRG iteration
  • Hamiltonian::NRG_block_A - Fills top-left part of the Hamiltonian matrix, usually diagonal which contains the eigenvaues of the previous iteration
  • Hamiltonian::NRG_block_BC - Fills the bottom-left and top-right parts of the Hamiltonian matrix, which contains the expectaion value of the perturbing operator(s) between previous step eigenstates and the newly added states of the computational basis
  • Hamiltonian::NRG_block_D - Fills the bottom-right part of the Hamiltonian matrix, which contains the expectaion value of the perturbing operator(s) on the newly added states of the computational basis
  • Hamiltonian::sweep_block_BC - Fills the bottom-left and top-right parts of the Hamiltonian matrix, which contains the expectaion value of the hamiltonian between previous step eigenstates and eigenstates of the previous step same iteration
  • Hamiltonian::Msize - Size of the Hamiltonian matrix at each NRG iteration
  • Hamiltonian::print_eigenValues - Prints eigenvalues to file
  • Hamiltonian::print_eigenVectors - Prints eigenvectors to file
  • matrix_elements::calculate_ExpVal - Calculates expextation value on the final eigenstates of a given operator. The only interface of matrix_elements to be strictly respected.

An example of such an application to the Quantum Harmonic oscillator in 1D is available in src/truspace_extension_example
