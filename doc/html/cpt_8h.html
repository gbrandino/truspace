Parameters
[in]pfirst index of the minimal model
[in]qsecond index of the minimal model
[in]r1first Kac index of the first field
[in]s1second Kac index of the first field
[in]r2first Kac index of the second field
[in]s2second Kac index of the second field
[in]r3first Kac index of the third field
[in]r3second Kac index of the third field return std::complex<long double> containg the structure constant for the given fields.
Beware that in the function call the s index (second index) comes before of the r index (first index) for every field
