Detailed Description

Hamiltonian Class.

Class that calculates and holds the Hamiltonian matrix and the function to calculates the elements needed for NRG and Sweep. For NRG/Sweep the structure of the matrix is

A B
C D

Where A is a matrix of size parameters::Nsize**2, B and C are of size parameters::Nsize* parameters::Nstep and C is of size parameters::Nstep**2
